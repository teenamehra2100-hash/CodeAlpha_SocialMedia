# CodeAlpha Social Media Platform

A full-stack social media application built during my CodeAlpha Full Stack Development Internship (Task 2).

## Features
- User profiles with avatars
- Post feed with real-time updates
- Like & Comment functionality
- Instagram-style stories bar
- LinkedIn-style professional sidebar
- Dark navy & red modern UI

## 🛠️ Tech Stack
- **Backend:** Django 4.x / Python
- **Frontend:** HTML5, CSS3, JavaScript
- **Database:** SQLite

## How to Run
1. Clone the repository
2. Navigate to backend: `cd backend/social_backend`
3. Run migrations: `python manage.py migrate`
4. Start server: `python manage.py runserver`
5. In a separate terminal, go to frontend: `cd frontend`
6. Run: `python -m http.server 5500`
7. Open `http://localhost:5500/index.html`
